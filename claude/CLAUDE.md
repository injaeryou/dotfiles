# 개인 규칙

모든 프로젝트에 공통 적용되는 전역 지침. 규칙 본문은 아래 파일에만 둔다 — 여기에 옮겨 적지 않는다.

## 규칙 (`~/.claude/rules/`, 매 세션 로드)

- `workflow.md` — 조사 → 개발 → 테스트 → 리뷰 → 커밋 순서.
- `principles.md` — 작업·실행 원칙, 실패 처리. 검증 없는 완료 선언 금지, 요청 범위만, 에러를 폴백으로 가리지 않기.
- `git.md` — 커밋 메시지·히스토리·PR. PR은 제목·본문 초안을 먼저 보여주고 승인받은 뒤 올린다.
- `docs.md` — 프로젝트 규칙은 `AGENTS.md`, AI 작업 문서는 `.docs/`(git 미추적).
- `audit.md` — git 저장소에서 점검 기록이 없거나 30일 지났으면 응답 끝에 한 줄로 점검 제안.
- `python.md` — `uv`, `ruff`, `pytest`.

## 스킬 (`~/.claude/skills/`, 필요할 때 로드)

- `project-audit` — 의존성·코드·로컬 환경·CI/CD 점검 절차와 `.docs/audit.md` 기록 형식.
