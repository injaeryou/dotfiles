## 정기 점검 (월 1회)

- git 저장소인 프로젝트에서 세션의 첫 작업 때 `.docs/audit.md`의 마지막 점검일(맨 위 회차)을 확인한다.
  - 파일이 없거나 30일이 지났으면 요청받은 작업은 그대로 하고, 응답 끝에 점검을 한 줄로 제안한다. 승인 전에는 점검을 시작하지 않는다.
  - 30일이 안 됐으면 언급하지 않는다.
  - 한 세션에 한 번만 제안한다.
  - 맨 위 회차가 `[제외]`이면 제안하지 않는다.
- 내가 거절하면 `.docs/audit.md` 맨 위에 회차를 남긴다 — 이 날짜도 마지막 점검일로 친다.
  - 이번만 거절: `## YYYY-MM-DD` + `- [건너뜀] 사유`
  - 이 저장소는 점검하지 않음: `## YYYY-MM-DD` + `- [제외] 사유`
  - `.docs/`가 없으면 `.docs/.gitignore`(내용 `*`)부터 만든다.
- 내가 승인하면 `project-audit` 스킬의 절차대로 진행한다.
